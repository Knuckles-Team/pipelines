# PIPE-CONNSPEC-001 requirements

| ID | Requirement | Verification |
|---|---|---|
| `PIPE-CONNSPEC-R001` | **Generated status with three hooks and four states.** The reference implementation lives in `pipelines_hooks/specs/`, exposing the hooks `spec-status`, `spec-decomposition`, and `spec-trailers`. Delivery status is generated, never hand-edited, and each requirement is in exactly one of the states SPECIFIED, LANDED, VERIFIED, or RETIRED. New landings use explicit Spec trailers or historical Spec subjects, never unrelated prose or none exemption reasons; historical receipts retain their existing validation. When specs exist, incomplete shallow Git history refuses generation and writes with exit 2 and a full-history fetch remedy, leaving status files unchanged; full history still rejects reverted or unreachable receipts. Repository ownership comes from origin or a sole configured remote, correcting stale checkout-derived owners without losing live legacy receipts; without an unambiguous remote identity, retain the old owner or finally the checkout name. | The files `pipelines_hooks/specs/status.py`, `decomposition.py`, and `trailers.py` exist, and `pipelines-hook spec-status --write` followed by `pipelines-hook spec-decomposition` runs clean in this repository. |
| `PIPE-CONNSPEC-R002` | **Test binding forms.** A test binds to a requirement with `@pytest.mark.spec("<ID>")` in Python or a `// spec: <ID>` comment in other languages, as parsed by `pipelines_hooks/specs/bindings.py`. | `pipelines_hooks/specs/bindings.py` exists and a bound test in this repository is picked up by `pipelines-hook spec-status`. |
| `PIPE-CONNSPEC-R003` | **The spec-delivery page.** `scripts/spec_dashboard*.py` is rendered through the reusable workflow `.github/workflows/pages_pipeline.yml` with `spec_dashboard_enabled: true`, and publishes at `https://knuckles-team.github.io/<repo>/spec-delivery/`. | `scripts/spec_dashboard.py` and `.github/workflows/pages_pipeline.yml` exist, and the workflow declares the `spec_dashboard_enabled` input. |
| `PIPE-CONNSPEC-R004` | **Reference callers in the five core repositories.** The reference callers are epistemic-graph (`release.yml`), agent-utilities (`advisory.yml`), graph-os (`pages.yml`), agent-connector-sdk (`pages.yml`), and agent-webui (`advisory.yml`).
