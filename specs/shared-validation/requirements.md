# PIPE-VALIDATION requirements

| ID | Requirement | Acceptance |
|---|---|---|
| `PIPE-VALIDATION-R001` | **Bounded shared repository validation.** The validation package runs declared offline checks with structured required and advisory outcomes. | The child requirements below cover the command. |
| `PIPE-VALIDATION-R001.1` | **Strict policy.** `validation/policy.py` rejects unknown keys, duplicate IDs or gates, unsupported gates, missing acceptance mappings, and invalid deadlines before dispatch. | `test_policy_refuses_ambiguous_checks` and `test_policy_accepts_repository_group`. |
| `PIPE-VALIDATION-R001.2` | **Passive events do no work.** `validation/cli.py` returns an explicit inactive result for post-merge, post-checkout, and post-rewrite without loading policy or dispatching checks. | `test_passive_git_event_does_not_dispatch` uses disposable Git repositories and sentinel tools. |
| `PIPE-VALIDATION-R001.3` | **Required checks fail closed.** `validation/runner.py` reports missing prerequisites separately; required failures, unavailable results, and timeouts block. Advisory outcomes remain visible. | `test_required_and_advisory_outcomes` and `test_missing_git_is_unavailable`. |
| `PIPE-VALIDATION-R001.4` | **Bounded execution.** `validation/runner.py` enforces check and run deadlines, terminates its process group, and records measured duration. SIGTERM and SIGINT clean up worker descendants while preserving the runner signal exit; prior signal policies are restored. | `test_deadline_terminates_child_process`, `test_run_budget_marks_remaining_checks`, and `test_runner_signal_cleans_worker_group_and_keeps_signal_exit`. |
| `PIPE-VALIDATION-R001.5` | **Actionable evidence.** `validation/cli.py` prints grouped concise results and writes a versioned report with check logs, remedies, acceptance IDs, and elapsed time. Published and self-run pre-commit registrations expose advisory output even when the aggregate exit is zero. | `test_summary_matches_evidence` verifies clean and failed runs; `test_advisory_report_is_visible_through_pre_commit` covers advisory fail, unavailable, and timeout through actual pre-commit. |
| `PIPE-VALIDATION-R001.6` | **Retain AU ignore acceptance.** The shared gitignore checker retains all 16 AU patterns and rejects tracked build, dist, and target families without confusing ordinary source filenames. | `test_au_ignore_acceptance_is_retained` runs real disposable Git fixtures. |

| `PIPE-VALIDATION-R002` | **Privacy identity provenance.** Match Git-display-name-only candidates in identity fields or explicit attribution. Account, host, home-path, email, explicit override and prohibited-catalog identities remain strict everywhere. Independent strict provenance wins when sources overlap. No product-name allowlist applies. A bare personal name outside attribution can pass when Git display name is its sole source. | `tests/hooks/test_privacy_provenance.py` exercises the real CLI, contextual attribution, independent sources, same-line leaks and catalog precedence. Existing catalog refusal tests remain required. |
